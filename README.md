# **AfkSync**

AfkSync is an authoritative AFK and absence tracking service designed for
staff tooling and operational insight on Paper servers.

This plugin intentionally avoids placeholders and cosmetic-only AFK logic,
focusing instead on deterministic state tracking and queryable context.

## **Current status**

**Stage 1 – Activity tracking (_in progress_)**

- Tracks player activity via movement events
- Maintains last-activity timestamps
- Clears AFK state on movement
- No scheduler or commands yet

This repository is under active development.
